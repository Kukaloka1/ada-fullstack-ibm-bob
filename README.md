# ADA — AI Delivery Architect

Two AIs are better than one.

Bob builds. Ada orchestrates and reviews. You lead.

ADA is a chat-first software delivery control cockpit for disciplined AI-assisted engineering workflows using IBM Bob.

## Stack

- Turborepo
- pnpm
- Next.js App Router
- TypeScript
- Tailwind CSS
- Supabase Postgres
- OpenAI-compatible LLM API
- IBM Bob IDE

## IBM Bob Hackathon Evidence

Relevant Bob task session reports must be stored in bob_sessions/.

## Workflow

Human Lead -> ADA -> IBM Bob -> ADA QA -> Release Gate -> Commit/Push.
